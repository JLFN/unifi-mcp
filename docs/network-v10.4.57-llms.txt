# Network API Documentation (v10.4.57)

> Network API reference for version v10.4.57. For all services and latest versions, see [llms.txt](https://developer.ui.com/llms.txt).

Authentication: All APIs use API Key authentication via the `X-API-KEY` header. Generate keys at unifi.ui.com.
